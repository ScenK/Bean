Chat

It's just a chat — until it isn't.

Ask anything and Bean answers right there. When something needs actual work, the same conversation offers to do it: the skill, the project, the exact prompt — all editable, nothing runs until you confirm.

  • Confirm-first cards. Every run is a proposal you can edit, retarget or cancel.
  • Agent mode. Open a live, multi-turn session with a coding agent inside the chat — streamed, stoppable, resumable.
  • Delegation that reports back. Headless runs stream in the background and fold their result into the conversation.
  • Drop anything. Images, PDFs, a link onto the avatar — Bean blooms its skills so you drop it on the right one.

Memory

It remembers you — and only what you said.

Bean keeps notes as you talk and saves the durable things — about you, your projects, your taste — so it knows you across sessions, not just within one.

  • Quote-cited. Every saved fact must cite your own words, or it isn't saved.
  • Scoped. Global facts, per-project facts, and an always-on “You” profile.
  • Private by speaker. In Discord or Teams, a DM stays yours; a channel's memory is shared.
  • Fast recall. Full-text search on local SQLite, with CJK-aware indexing.
  • Every save is undoable. “Memory updated” rows in the chat carry a one-tap Forget.

Dream

While you sleep, Bean dreams.

Memory that only grows turns to noise. Once a day — after enough new memories — Bean consolidates: merging duplicates, sharpening vague facts, letting go of stale ones. The model only suggests; code decides.

  • Guard-railed. Never merges across projects, categories, sources or speakers, and never touches private memories.
  • Can't wipe you. Drops are capped per run, so a bad night can't erase what Bean knows.
  • Reversible. Undo the last dream in one tap — your own edits since then are kept.

ChatOps

Reach it from anywhere.

Wire Bean into Discord or Teams and message it from your phone or your work chat. Same brain, same confirm-first cards — Bean doesn't have to be in front of you to work for you.

  • Roles, enforced twice. Owner, admin, member, guest — each gets its own tools, re-checked when a card is tapped.
  • Live agent sessions in a channel. A war-room anyone can steer, or restricted to you and your co-drivers.
  • Listens, doesn't barge in. Only a mention, reply or DM gets a turn; the rest is kept as context.
  • Hand off seamlessly. Carry a desktop chat — or a running agent session — into a Discord thread.

Sprouts

Plant a task once. It keeps growing.

A sprout is a pipeline that runs while you're away — on a cron schedule, or watching a feed or a command with no model call per check. Chain agent, chat and shell steps; gate on a verdict to stop, branch or loop; drain a to-do queue; and drop the result wherever you want it.

Cron or watch

Morning digests on a schedule, or a watched RSS feed / shell command that only queues what's new.

Three step kinds

Delegate to a coding agent, chat on Bean's own model, or run a deterministic command — mix them freely.

Gates & routes

A step's PASS/FAIL verdict or named choice can stop, branch or loop the flow. Sessions can continue across steps.

To-do queues

Queue tasks from chat, Discord or Teams; the sprout works them down one at a time.

Results, delivered

Post to a channel or DM, file a note, or pop a desktop notification — or only speak up when a run needs you.

Learns from its runs

A retro step reads past runs and drafts skill improvements for you to review — never applied silently.

And more

Skills are markdown

Notes & images

Bean writes and links notes, generates images, and embeds them — searchable alongside everything else.

Reminders

“Remind me at 4” works on the desktop and in any chat, delivered where you asked.

Built-in terminal

A terminal pane right in the chat window, next to the agent that's working in it.

Two themes

Hearth, warm amber on cream. Graphite, cool blue at night. Bean wears both.

Trust

“Always asks before it acts.” Not a slogan — a rule enforced in code.

Your key, your machine

Bean thinks with your own OpenAI key and works through the CLIs you already use. No middleman service.

Private by default

Your data dir is locked to your account. Remote images in replies are never loaded, so nothing can beacon out.

Least privilege

Spawned agents get an allow-listed environment, never your whole shell. Untrusted links are fetched with private-network blocking.

Saved text stays data

Notes and memories are framed as quotes, never as instructions — what Bean read can't steer what Bean does.

Get Bean

One brain. Run it where you work.

Bean is a core (the brain, your data, sprouts, bots and coding agents) and a desktop app that attaches to it. Put the core on your Mac, a Linux box or a container, then open Bean from a Mac or a Windows PC.

Desktop

The avatar, the chat and every panel.

macOS · Apple Silicon

Full app, with a local core built in. Download .dmg

Windows

Attaches to a core on another machine over SSH. Download .exe

Core

Sprouts, reminders and the Discord / Teams bots, with no screen needed.

macOS & Linux

Native service (launchd / systemd), signed release, self-updating. Download .tar.gz 
tar xzf bean-core-<ver>.tar.gz
./bean-core-<ver>/install.sh

Docker

An isolated chat & sprout core for a household or a team. Guide 
docker build -t bean .
docker run -d -v bean:/data -e TZ=America/Toronto bean
Then add user@host in the desktop app's Cores panel. It connects over SSH, with no open port. Release notes · Headless guide
