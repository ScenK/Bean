# Ask on the ticket

The ticket below isn't clear enough to implement. Post one comment on it (for a GitHub issue,
`gh issue comment <url> --body-file -`) that:

- says in one line that work is paused until these are answered,
- lists the questions from the lint report you were given — at most three, each answerable in
  a sentence,
- doesn't guess at answers or start the work.

Don't change labels, assignees, or the ticket body. Output: the comment's URL.
